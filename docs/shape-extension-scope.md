# 精細形状と追加検証の範囲

Issue #28の設計決定。既存14種類を維持し、追加実装を次の2段階に絞ります。
この文書の新しいkindや属性は、まだCLI・保存形式では受け付けません。

## 追加形状

| 順序 | 形状 | 必要な入力 | 表示と占有範囲 |
| --- | --- | --- | --- |
| 1 | L字ソファ | 直方体2〜4個のローカル座標・寸法 | 同じ直方体群を描画と判定に使用 |
| 2 | 円形テーブル・円柱収納 | 直径・高さ、天板厚と脚 | 同じ外接多角柱を描画と判定に使用 |

L字ソファは内部の空き領域を使うことが目的です。占有部は親の外接箱内にある
正の寸法だけを許可し、支持面は既存supportsを使います。任意メッシュ、
布の変形、実物の細かな曲面は対象外です。
円形は外接正多角形（初期案24辺）に統一し、外接による余白を寸法欄に示します。
脚間を使う形状は天板と脚を別の占有部にします。
geometryとsceneが多角柱に対応してから追加し、見た目だけを真円にしません。

## 属性と判定

| 属性 | 単位・根拠 | 初期実装での扱い |
| --- | --- | --- |
| 占有部の座標・寸法 | mm、各値のevidence | 幾何検証に利用。不明なら仮扱い |
| 家電の必要離隔 | 各方向mmまたはnull、出典・型番 | 入力済み方向だけ幾何比較。不明方向は未確認 |
| 開閉に必要な領域 | 根拠付きローカル直方体群 | 静的領域との重なりだけ判定 |
| 重量・棚の耐荷重 | kgまたはnull、出典 | 記録・表示のみ、強度計算はしない |
| 壁固定 | 未確認・必要・確認記録あり | 記録のみ、耐震性・壁材強度は判定しない |

物理属性は画像の種類判定やconfidenceから補完しません。メーカーの説明書や
実測を出典として残し、人の明示操作で確認状態を変更します。
重量の合計だけで棚の強度を保証せず、局所荷重・重心・取付条件は対象外です。
離隔が入力済みでも放熱性能が検証されたとは扱いません。

表示は「幾何: 問題なし／問題あり／寸法不明」と「物理条件: 未評価」を分けます。
後者を既存validation.validから導出しません。個別属性のconfirmedをもって
「安全確認済み」とは表示しません。現行validも実装済みの幾何と根拠状態だけです。

## 保存・実装

占有部と物理属性を受け付ける際はSchemaと保存形式を一緒に更新します。
version 1/2は従来の占有部へ変換し、見た目・判定を勝手に変更しません。
新形式を知らない旧CLIはバージョン不一致で拒否します。
未知kindは現行と同じくcategoryと注意を残す仮のboxにし、寸法不明なら3Dを
省略して画像候補と一覧を残します。新属性を読み捨てて有効と判定しません。

Node・ブラウザ共通のscene/geometryで占有部を正規化・変換し、viewerは
その結果を描画します。Schema、CLI、export、移行、手順も同時に更新します。

## 受け入れ確認

L字の内側への配置、任意角の回転、親子変換、親の外へ出る占有部、円形の接触、
支持面、開閉領域、不明離隔を回帰テストにします。
全描画頂点が検証の占有範囲内にあり、各固体部が表示されることを確認します。
Chrome offlineの選択・寸法・仮表示、JSON復元、HTML単体配布も確認します。
物理属性が不明な例を「検証済み」と表示しないことを明示的に検証します。
lint、単体・CLI、demo、browser、packageを実行し、表示時間・容量も記録します。
