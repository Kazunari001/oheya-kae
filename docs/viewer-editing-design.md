# オフラインHTMLでの編集・保存の設計

Issue #27の設計決定。これは実装前の仕様で、現行HTMLには編集機能はありません。
初期版は1物体ずつの数値編集とJSONダウンロードを対象にします。
ドラッグ配置、部屋輪郭・棚板・親子関係の編集、HTML自体の上書きは後続です。

## 操作

一覧・画像枠・3Dで選択した家具または小物の詳細に「編集」を設けます。
開口部と画像だけの候補には表示しません。配置案の比較中は「現在の配置へ戻る」
操作を先に案内し、どの配置を変更するか曖昧にしません。

フォームは幅・奥行・高さ、x・y・z、回転をmm・度で表示します。
親付き物体は「親からの相対位置」、独立物体は「部屋内の位置」と明記します。
数値0と不明を分け、不明は専用チェックでnullにします。未配置物体も編集可能です。
x/z/回転のnullは許可せず、寸法・設置高さのみ不明にできます。
変更していないフィールドとその根拠は保持します。

状態は編集前の状態を表示し、変更時の既定をestimatedにします。
推定更新には根拠の入力が必須です。「実測・現物で確認した」を明示的に選んだ
非null属性のみconfirmedにできます。画像のconfidenceで確認済みにしません。
状態の変更だけでも履歴を作ります。

「検証して反映」でコピーを正規化し、支持関係と幾何を再検証します。
不正値・参照切れは該当欄に表示し、反映しません。
衝突・はみ出しは図と問題一覧で示し、「問題を残して反映」を別操作で選べます。
この場合「配置に問題あり」のままとし、有効な配置と表示しません。
不明寸法はunknown、問題なしでも未確認属性があれば仮表示を維持します。
入力中の値で元データや3Dを直接変更しません。

「キャンセル」は編集開始時へ戻し、「元に戻す」は直前の反映単位を取り消します。
取り消しも復元前の値を根拠履歴に残します。反映時は古い配置案を無効にし、
親を動かした場合は子のローカル値を保持したまま3Dと検証結果を更新します。
未保存状態は常時表示し、保存前にタブを閉じるとブラウザ標準の確認を出します。

## 保存

「プロジェクトJSONを保存」で、反映済みデータをversion 2 / mmのJSONとして
Blob URLからダウンロードします。ファイル名は元プロジェクト名と版・日時を使い、
元ファイルは上書きしません。ダウンロード開始時にBlob URLを適切に破棄します。
ダウンロード完了を検知できないブラウザでは「保存先を確認してください」と示し、
未保存表示を消すのは利用者が「保存を確認した」を選んだ後にします。
編集中のフォームがあれば、反映またはキャンセルしてから保存します。

JSONには全物体・親子関係・支持面・元画像・解析の原回答と検出枠・根拠履歴を含め、
表示用のworld座標や一時的な選択状態は保存しません。
元の解析結果は書き換えず、補正済みプロジェクトを別の版として識別します（#10）。
ダウンロードしたJSONは次の既存CLIで検証・HTML化できます。

```sh
node bin/oheya-kae.js --project output/edited.json state
node bin/oheya-kae.js --project output/edited.json layout validate --strict
node bin/oheya-kae.js --project output/edited.json export --output output/edited.html
```

File System Access API、サーバー、localStorage、外部通信は必須にしません。
元HTMLの埋め込みデータはリロードすると元に戻るため、保存と再出力を説明します。

## 実装の分割

1. 正規化・revise・検証をNode/DOM非依存のモジュールへ切り出します。
   現在のmodel.jsはnode:crypto、detections.jsもNode依存を持つため、そのまま
   ビューアーへimportしません。ID生成は境界で注入します。
2. 編集状態・コピー検証・反映と取り消しを実装します。親子の変換はscene.js、
   幾何はgeometry.jsを共有し、CLIとブラウザで別の判定を作りません。
3. フォームとJSONダウンロードを追加し、キーボード操作、エラーへのフォーカス、
   aria-liveでの反映結果、小画面でのスクロールを確認します。

## 受け入れ確認

Chromeのfile://かつofflineで、推定幅の修正→衝突確認→反映→JSON保存→CLI読込→
HTML再出力を通します。親の移動・回転、棚内の本の相対位置、不明値、未配置、
明示的なconfirmed、既存履歴、キャンセル・取り消し、配置案の無効化を検証します。
不正寸法・棚板を越える子・参照切れでは元データが変わらないことを確認します。
元画像や原回答の保持、特殊文字のHTMLエスケープ、外部通信ゼロも必須です。
実装時はlint、単体・CLIテスト、demo、browser、package検証を実行します。
